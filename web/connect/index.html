How to connect

Train in the iPhone app. Claude or ChatGPT can plan and look at your history. They cannot log a set for you — that stays on the phone on purpose.

Back to the app

1. Get the app

Install MCP Strength, create an account, and confirm the email we send. Log a workout there. This site is not a logger.

2. Add the connector

In Claude (or ChatGPT, when you use a plugin there), add a custom connector. The URL is:

https://mcp.mcpstrength.com

Paste that exactly. You will land on this site, sign in with the same email as the app, and tap Allow.

3. What it can do

Once connected, the assistant can list and create exercises, read and edit templates, build or delete a program, and read completed workout history. It cannot record a live session from chat.
